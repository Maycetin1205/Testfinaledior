# Chef-Maske

Die alten Masken Empfang und Behandlung des Chefs, mit Beispielbeleg. Seit
12.10.2026 kein Maßstab mehr für den Editor; Maßstab sind die Masken in
`masken/`. Hier nur nachschlagen, wie SoftEngine geschrieben wird
(PUT_RELATION-Wege, etwa 01 für den Adressstamm). Was belegt ist, steht in
`../softengine-wiki/kontrakte.md`.
